\section{Metodología}
El equipo acuerda la estructura, reparte las secciones y sincroniza antes de
editar. Como ejemplo de contenido matemático, la media de una muestra es
\begin{equation}
    \bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i.
\end{equation}
Al finalizar cada bloque de trabajo, se guarda el documento, se comprueba
el PDF y se sincroniza con una descripción breve de los cambios.
